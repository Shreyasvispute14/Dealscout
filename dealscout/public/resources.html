Quick setup

Run it locally in under a minute

  1. Install Node.js (LTS) from nodejs.org.
  2. Open the dealscout folder.
  3. Windows: double-click setup.bat · macOS/Linux: run ./setup.sh.
  4. Open http://localhost:3000.

Or manually

Single command

  1. Open a terminal in the dealscout folder.
  2. Run node server.js.
  3. No npm packages or database installation required — data lives in plain JSON files.
